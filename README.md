# 🏈 College Football Player Dataset (JSON)

A structured JSON dataset containing college football player information, designed for use in mobile and backend applications.

---

## 📊 Overview

This repository contains a collection of college football player data stored in JSON format.  
It is used as a data source for applications that display player information, statistics, and media links.

The dataset is publicly hosted and optimized for easy consumption by frontend and backend projects.

---

## 📁 Data Structure

The main JSON file includes an array of player objects with the following fields:

- `name` – Player name  
- `school` – College or university  
- `position` – Player position  
- `year` – Class year  
- `img` – URL to player headshot image  
- `stats` – Link to player statistics page  
- `yt` – Link to highlight video (YouTube)

---

## 🔗 Usage

This dataset is designed to be fetched directly via raw GitHub URL.

Example: https://raw.githubusercontent.com/DavidJASC20/CFB/main/players.json
